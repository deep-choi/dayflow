개인정보처리방침

제이엔메드는 Dayflow의 앱과 웹 서비스에서 다음 정보를 처리합니다.

처리하는 정보와 목적

Google 로그인 정보(이메일, 계정 식별자, 이름·프로필 사진), 일정, 할 일, 메모·일기, AI 대화와 첨부 이미지, 페르소나, 앱 설정과 AI 연결 설정(직접 입력한 API 키 포함), AI 사용량. 로그인, 서비스 기능 제공, 계정 간 동기화, 사용량 관리, 오류 대응과 안전한 서비스 운영에 사용합니다. 기기에는 로그인 세션, 설정과 기능에 필요한 로컬 기록이 저장됩니다. 서버·호스팅 제공자는 접속 IP와 요청·오류 로그를 처리할 수 있습니다.

서비스 제공자와 공개 정보

Google 로그인과 Supabase 인증·데이터베이스를 이용합니다. 웹과 안내 페이지는 Google Firebase Hosting에서 제공합니다.

개인 기록은 계정별로 저장됩니다. 공유 기능을 사용하거나 외부 서비스에 직접 자료를 보내면 선택한 대상에게 해당 정보가 전달됩니다.

AI와 음성 처리

AI 대화 시 질문, 필요한 대화 문맥과 사용자가 선택한 일정·할 일·메모 및 첨부 자료가 선택한 AI 제공자에게 전송됩니다. 기본 체험은 Google Gemini를 이용하며, 설정에 따라 OpenAI, Anthropic, xAI, DeepSeek, Qwen, Kimi, GLM 또는 직접 지정한 서버를 사용할 수 있습니다. API 키는 선택한 제공자 인증에 사용되며 연결 설정과 함께 계정에 저장될 수 있습니다. AI 요청에 비밀번호, 주민등록번호 등 불필요한 민감정보를 넣지 마세요. 제공자의 처리 위치·보관 방식은 각 제공자의 정책을 따릅니다.

보관과 삭제

계정과 서비스 기록은 서비스 이용 중 보관하고 계정 삭제 시 함께 삭제하는 것을 원칙으로 합니다. 신고·분쟁 대응 또는 법적 의무로 별도 보관이 필요하면 삭제 요청 처리 시 해당 항목과 보관 사유·기간을 안내합니다. 다른 기기에 남은 다운로드 파일과 로컬 기록은 해당 기기에서 직접 삭제해야 합니다.

이용자의 선택

앱에서 기록을 관리하고 로그아웃할 수 있습니다. 마이크·파일 접근은 해당 기능을 선택할 때만 요청하며 기기나 브라우저 설정에서 철회할 수 있습니다. 계정 삭제는 계정 삭제 안내에서 요청할 수 있습니다. 개인정보 열람·정정과 처리 관련 문의는 운영자 이메일로 보내 주세요.

보호 조치

서비스 통신에는 HTTPS를 사용하고 계정 인증과 접근 규칙으로 개인 데이터 접근을 제한합니다. 개인정보 판매와 광고 타기팅을 위해 수집하지 않습니다.
